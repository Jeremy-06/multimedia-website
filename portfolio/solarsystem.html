Blender Guide

How to render your planet in Blender

Download the scripts and textures, update the local texture path, then run the Python script inside Blender's Scripting workspace.

Download All Resources
Steps 1-3

Prepare the files

  • Download the provided .zip file containing the Blender Python script and texture images, such as jupiter.jpg and universe.jpg.
  • Extract the .zip file to a folder and remember the exact location, such as C:\Users\YourName\Desktop\PlanetProject.
  • Open the downloaded Python script in a text editor, find base_path, and change it to your extracted folder path.
  • Keep the r before the quotation marks, for example: base_path = r"C:\Users\YourName\Desktop\PlanetProject" .
  • Open Blender, close the splash screen, go to the Scripting tab, and click + New.
Steps 4-6

Run and render

  • Copy all script code from your text editor and paste it into Blender's text editor.
  • Click the Run Script play button or press Alt + P to generate the planet, moons, cameras, and lighting.
  • Hover over the 3D viewport, hold Z, and drag upward to select Rendered.
  • Press Spacebar to watch the camera animation and orbiting moons play in real time.
  • In Output Properties, choose the save folder, change File Format to FFmpeg Video, then set Container to MPEG-4.
